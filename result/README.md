# Legacy simulation result archive

> この単数形 `result/` は、引き継ぎ資料と2026-10-24以前に集約した結果を
> 保持する旧アーカイブである。新しいシミュレーションはここへ保存しない。
> 新規実行の正本は [`results/`](../results/README.md)、標準配置は
> `results/runs/<実験ID>/<Eval>/seed-<seed>/` とする。

このディレクトリは、過去に集約した `mcs-tiv` の評価証拠を保持する。
結果の出自を混ぜないため、引き継ぎ資料・自分たちの再現実験・提案手法を分離する。

## ディレクトリ

| ディレクトリ | 内容 | 扱い |
| --- | --- | --- |
| `handover-reference/` | 山下研究室から引き継いだ結果とDriveミラー | 比較用の参照値。自分たちの再実行結果として扱わない |
| `reproduction/` | 2026年9月〜10月に行った再現・監査・環境比較 | 実行条件、seed、環境、完走状況を確認して使う |
| `proposed-method/` | 2026-10-24時点で集約した減速伝播の結果 | 旧スナップショット。新規出力には使わない |

## 共通ルール

- この旧アーカイブへ新しい実験を追記しない。
- 集計値だけでなく、条件を固定する `manifest.json`、seed別結果、監査結果、ログを対応づける。
- 引き継ぎ値、再現値、提案手法の値を同じファイルへ混在させない。
- 生成コードの丸ごとの複製、Pythonキャッシュ、仮想環境は保存しない。コード版はGit commitとmanifest内のハッシュで識別する。
- 大容量のFCD `sumoStat.xml`はこのGit管理ディレクトリへ重複保存しない。必要な場合は各READMEに記載した元保存先を参照する。
- HTMLや論文へ数値を転記するときは、対象実験のJSONまたはCSVを正本とし、ログ上の途中表示から推測しない。

## 2026-10-24の集約について

既存の保存先は削除・移動せず、再利用に必要な結果ファイルだけをここへコピーした。
そのため、ここにあるファイルは旧保存先のバックアップでもあるが、旧保存先そのものは引き続き残っている。
