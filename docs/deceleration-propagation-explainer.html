MCS-TIV｜動的後続影響評価
01 / 13
01 / RESEARCH PURPOSE

後続車両への影響を
リアルタイムに計算する。

MCSで交渉を受け入れたときの影響を、あらかじめ作った距離係数ではなく、通信で得た現在の車間・速度・予定軌道・車両性能からその場で推定する。減速伝播は、その影響を因果的に計算するための手段である。

02 / PAPER BASELINE

出発点は、論文のTIV。

\[ \mathrm{TIV}(P)=\Delta t(P)+\alpha E_R(P)+\beta a_{\max}(P) \]

小さいTIVを持つ軌道を優先する。論文条件では \(\alpha=-0.1\)、\(\beta=0.1\)。

TIME TERM

到達時間  \(\Delta t\)

現在から、2本の軌道が交差する衝突候補地点へ到達するまでの時間。

ENVIRONMENTAL TERM

後続環境  \(E_R\)

10秒後の速度と、距離から求めた係数を掛けて合計する。

\[E_R(P)=\sum_i v_i(H)R(X_i)\]
PERFORMANCE TERM

最大加速度  \(a_{\max}\)

加速性能が低い車両ほどTIVを小さくして、判断上優先しやすくする。

本研究では、このTIVを出発点として、後続車両の影響を表す環境項 \(E_R\) の算出方法に注目する。

03 / PROBLEM & APPROACH

TIVの環境項に、
どんな問題があるか。

進行方向 →
後続3直接は見ない
後続2後続1に反応
後続1交渉車に反応
交渉車速度変更の起点
問題点

予備実験から \(R(X)\) を定義

交渉車からの距離を固定関数へ入力し、現在の交通状態でも同じ影響関係が成り立つものとして評価する。

提案アプローチ

受信した現在状態から毎回計算

車間・速度・予定軌道・加減速性能を使い、先行車の変化によって後続車が実際に速度計画を変えるかを逐次推定する。

そこで固定距離係数 \(R(X)\) を、隣接車間の減速伝播と速度回復を逐次計算した後続影響へ置き換える。

説明の要点：TIVそのものを否定する研究ではない。TIVの環境項が固定係数に依存する点を問題とし、その計算方法を動的にする。

04 / ALGORITHM POLICY

後続影響を、隣り合う車両の
速度変化として順番に追う。

01 / DEFINE

「影響が伝わった」を定義

受入れ候補で後続車が予定速度を維持できず、拒否候補より追加の減速が生じた状態とする。

02 / LOCAL CHECK

まず1台後ろを判定

現在の車間・速度・予定軌道・加減速性能から、直前の車両に対して安全に走れる速度を求める。

03 / PROPAGATE

結果を次の車両へ渡す

各候補で更新した後続車を次の先行車として同じ判定を繰り返し、受入れと拒否の速度差が消えた地点で止める。

INPUT受入れ・拒否の候補軌道
→
JUDGE予定速度を維持できるか
→
UPDATE必要なら速度を下げる
→
REPEATさらに1台後ろへ

この判定に必要なのが、「現在の車間で安全に走れる最大速度」である。次のスライドでは、その安全速度を停止条件から求める。

説明の要点：距離そのものを影響量とはしない。候補軌道によって後続車の速度計画が実際に変わったときだけ、減速が伝わったと数える。

05 / SAFE FOLLOWING SPEED

先行車両がきつめのブレーキをかけたときに、
安全に止まれる速度を求める。

停止に必要な空間

最低車間
\(D_0\) 反応中の移動
\(\tau v_i\) 制動距離の差
\(\frac{v_i^2}{2b_i}-\frac{v_{i-1}^2}{2b_{i-1}}\)
\[ g_i \ge D_0+\tau v_i+ \frac{v_i^2}{2b_i}- \frac{v_{i-1}^2}{2b_{i-1}} \]

現在の車間が、最低車間・反応距離・制動距離の差を上回れば安全に停止できる。

\[ v_i^{\mathrm{safe}} =-b_i\tau+ \sqrt{ (b_i\tau)^2+ 2b_i\left( g_i-D_0+ \frac{v_{i-1}^2}{2b_{i-1}} \right) } \]

停止条件を後続車の速度 \(v_i\) について解いた、現在許される最大速度。

\(g_i\)
先行車と後続車の現在の純車間
\(D_0\)
停止後にも残したい最低車間
\(\tau\)
後続車が減速を始めるまでの反応時間
\(b_i, b_{i-1}\)
後続車と先行車について、軌道計算で許容する最大減速度の大きさ

固定的な影響度を与えるのではなく、現在の車間・速度・軌道計算で許容する最大減速度から、後続車がいま何m/sまでなら安全かを毎時刻計算する。

06 / DECELERATION AND RECOVERY

減速だけでなく、影響が消えた後の
速度回復まで追う。

\[ v_i^{\mathrm{target}}(k+1) =\min\left( v_i^{\mathrm{planned}}(k+1), v_i^{\mathrm{safe}}(k) \right) \]

安全だからといって、元のFrenet予定速度より勝手に速くしない。

\[ \begin{aligned} v_i^{\min}(k+1)&=\max\!\left(0,\,v_i(k)-b_i\Delta t\right),\\ v_i^{\max}(k+1)&=v_i(k)+a_i\Delta t \end{aligned} \]

ここでの \(b_i\) は、軌道計算で許容する最大減速度であり、1ステップ後の速度の下限を決める。\(v_i^{\min}(k+1)\le v_i(k+1)\le v_i^{\max}(k+1)\)。

\[ v_i(k+1)= \begin{cases} v_i^{\min}(k+1) & \left(v_i^{\mathrm{target}}(k+1)\lt v_i^{\min}(k+1)\right)\\ v_i^{\mathrm{target}}(k+1) & \left(v_i^{\min}(k+1)\le v_i^{\mathrm{target}}(k+1)\le v_i^{\max}(k+1)\right)\\ v_i^{\max}(k+1) & \left(v_i^{\mathrm{target}}(k+1)>v_i^{\max}(k+1)\right) \end{cases} \]

目標速度が上下限の内側ならそのまま使い、外側なら到達可能な下限または上限まで動かす。

INDEX & TIME
\(i\)
車列内の車両番号。\(i-1\) は1台前の先行車
\(k\)
予測計算の時刻ステップ番号
\(\Delta t\)
1ステップの時間幅［秒］
\(v_i(k)\)
時刻 \(k\) における車両 \(i\) の予測速度［m/s］
SPEED & PERFORMANCE
\(v_i^{\mathrm{planned}}\)
減速影響がなければ予定軌道で出す速度
\(v_i^{\mathrm{safe}}\)
先行車がきつめのブレーキをかけても安全に止まれる最大速度
\(v_i^{\mathrm{target}}\)
planned速度とsafe速度の小さい方
\(a_i\)
車両 \(i\) の最大加速度［m/s²］
\(b_i\)
車両 \(i\) の軌道計算で許容する最大減速度の大きさ［m/s²］
\(v_i^{\min},v_i^{\max}\)
車両性能上、次のステップで到達できる速度の下限と上限

同じ \(b_i\) でも役割は異なる。\(v_i^{\mathrm{safe}}\) では停止距離から安全な速度上限を求め、\(v_i^{\min}\) では1ステップで許容する減速量を求める。快適減速度ではなく、軌道計算上の制約値として扱う。

08 / IMPACT METRIC

ある一時点の速度ではなく、
予測区間全体の速度低下を積み上げる。

ONE VEHICLE

車両ごとの時間損失

\[ D_i^q=\int_0^H\left(1-\frac{v_i^q(t)}{v_i^{\mathrm{free}}}\right)dt \]

自由走行10m/sに対して8m/sで10秒走るなら、\((1-8/10)\times10=2\)秒の損失。

ACCEPT VS REJECT

受け入れによって増える総損失

\[ I_{\mathrm{prop}}=\sum_i\left(D_i^{\mathrm{accept}}-D_i^{\mathrm{reject}}\right) \]

正なら受け入れで悪化、負なら受け入れで改善。単位はvehicle-seconds。

INPUT現在状態と2つの候補
→
ROLL OUT隣接車間で10秒予測
→
COMPARE受入れ−拒否の損失差

速度低下の大きさと継続時間を同時に数えるため、短い小減速と長い停止を区別できる。

説明の要点：10秒後の速度を単独で使うのではない。10秒は速度低下を積算する上限であり、途中で影響が消えた場合は自然終了、消えない場合は打切りと記録する。

09 / PROPOSED DECISION

性能項を別に足さず、
減速と回復の結果として評価する。

\[ \boxed{ S_{\mathrm{prop}} = \left(\Delta t_{\mathrm{pl}}-\Delta t_{\mathrm{de}}\right) -\lambda I_{\mathrm{prop}} } \]

\(S_{\mathrm{prop}}\ge0\) なら要求を受け入れ、負なら拒否する。安全に成立しない候補は、この比較より前に除外する。

\(\lambda\) AND \(\alpha\)

役割は論文の \(\alpha\) の後継

どちらも後続環境を判断へ反映する重み。ただし、\(\alpha\) は速度×距離係数、\(\lambda\) は時間損失差へ掛けるため、同じ数値を流用できない。

NO DOUBLE COUNTING

独立した \(\beta a_{\max}\) は外す

加速度・減速度はロールアウト内で速度変化と回復時間を変え、すでに \(I_{\mathrm{prop}}\) へ反映される。

方式後続影響独立性能項目的
論文TIVte固定 \(R(X)\)なし論文比較
論文TIVtep固定 \(R(X)\)あり論文比較
提案Prop動的減速伝播なし主提案
Prop+Performance動的減速伝播あり二重評価の検証

説明の要点：「性能項を消した」のではなく、性能を事前の優先ルールから、今回の交通状態で実際に生じる速度低下と回復時間の計算へ移した。

11 / EVALUATION FRAMEWORK

評価は、4つの問いに分ける。

01 / VALIDITY

伝播計算は設計どおりか

  • 受入れと拒否の差の符号
  • 安全車間と加減速上下限
  • 影響台数・自然終了・範囲外打切り
  • vehicle-seconds集計の単位と整合性
02 / TRAFFIC EFFECT

MCS全体は改善したか

  • 平均速度・timeLoss・通過台数
  • 停止回数・最大減速度
  • 最小車間・TTC・衝突
  • ALW / ACT / SPD / UTF / TIVte・TIVtep / Propの比較
  • \(\lambda\) 感度とProp / Prop+Performanceの差
03 / REAL-TIME COST

判断は制御周期内に終わるか

  • 交渉判断1回の計算時間
  • 後続車数 \(N\) と実行step数
  • 早期終了率と最悪時間
  • メモリ使用量とスケーリング
04 / COMMUNICATION

情報が古い・欠ける場合も安定するか

  • 理想通信との判断一致率
  • 遅延・ゆらぎ・欠損・更新周期
  • 古いMCMの検出と安全側処理
  • 通信条件による交通指標の劣化

同じモデルで予測と走行を行った一致だけを「予測精度」としない。計算の整合性、交通流の改善、実時間性、通信耐性を別々に示す。

12 / COMPUTATION COST

重さは、理論量と
交渉ごとの実測時間で確かめる。

\[ K=\frac{H}{\Delta t}=\frac{10}{0.1}=100, \qquad C_{\mathrm{rollout}}\approx 2NK \]

\(N\)は影響候補の後続車両数。係数2は受入れ・拒否の2候補を比較するため。

LIGHTWEIGHT UPDATE

1stepで行うのは一次元更新

  • 車間・安全速度の計算
  • 速度の上下限処理
  • 位置更新と時間損失の加算
  • Frenet軌道の全候補生成は行わない
EARLY TERMINATION

100stepは上限とする

  • 受入れと拒否の速度差が消えた
  • 次の後続車に影響が伝わらない
  • 通信範囲や予測時間の上限に達した
  • 交渉が発生したときだけ実行する
記録値なぜ必要か報告方法
判断時間0.1秒の制御周期に対して遅すぎないか中央値・p95・p99・最大値
\(N\) と実行step数車列長と予測時間に対する伸び方を確認する\(N\)別・\(H\)別のスケーリング
終了理由毎回100stepまで計算していないか自然終了・範囲外・時間打切りの割合

100msは減速伝播だけの予算ではなく、軌道生成や衝突判定も含む制御全体の周期。伝播計算がその一部として十分短いことを実測で示す。
