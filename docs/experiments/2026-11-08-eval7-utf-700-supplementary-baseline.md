# Eval.7・700/1000 UTF追加対照

- 台帳ID: `2026-11-08-eval7-utf-700-supplementary-baseline`
- 状態: `planned`
- 位置づけ: `supplementary baseline`
- 開始日: 2026-11-08

## 目的

700/1000台/時の独立holdoutで山下TIVtepとterminal-heldを上回った
integrated lambda=2を、山下論文の合流Eval.7で最も高い全車平均速度を示した
UTFと同一条件で追加比較する。UTFの結果を見て提案方式や係数は変更しない。

## 仮説と比較対象

- 仮説: integrated lambda=2は、UTFに対しても全車平均速度と流出台数を
  低下させず、山下TIVtepの合流局面の弱点を局所的に改善する。
- 主要対照: UTF。方式番号`alpha=5`。
- 既存の比較対象: 山下TIVtep、terminal-held lambda=2、integrated lambda=2。
- 主要指標: 全車平均速度。副指標は合流側／本線側速度、停止時間、
  急減速時間、流出台数、承諾率、物理衝突。
- 解釈: これまでの結果を見た後の追加対照であり、新規の一次仮説検証とは
  主張しない。結論は700/1000条件に限定する。
